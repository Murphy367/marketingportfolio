# Murphy Tang — Marketing Portfolio

Interactive marketing portfolio: project stories told in chapters with boards, quizzes, flip cards, a crisis-response simulator, a launch calendar and a perceptual map.

Live site: https://murphy367.github.io/marketingportfolio/

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `assets/` — full-size project boards
- `thumbs/` — smaller images used in the grid
- `Murphy_Tang_Marketing_Portfolio.pdf` — PDF version
